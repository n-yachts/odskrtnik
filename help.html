Odškrtník

Zaškrtávací seznamy, které se dají opakovaně odškrtávat: kontrola před vyplutím, zazimování lodi, balení na cesty. Před každým použitím seznam vynulujete a jedete od začátku.

  • Každý seznam je Google Tabulka ve vašem Disku: kategorie, položky a zatržítka. Upravovat ho můžete v aplikaci i přímo v Tabulkách.
  • Položky mohou mít typy (hory, moře, služební cesta…). Při startu vyberete, na co se chystáte, a uvidíte jen to, co k tomu patří.
  • Seznam můžete sdílet s posádkou nebo rodinou – odškrtávat může víc lidí najednou.
  • Funguje i bez signálu, odškrtnutí se odešlou po připojení.

První spuštění

Při prvním otevření vás provede průvodce. V Google Cloud je potřeba jednou povolit přístup k Tabulkám a Disku. Je to zdarma.

Máte už projekt v Google Cloud (třeba pro jinou aplikaci)? Můžete použít ten – zkontrolujte souhlasovou obrazovku a Client ID a doplňte, co chybí: hlavně tři API (krok 2) a API klíč (krok 5).

1. Projekt v Google Cloud

Máte-li už projekt, v konzoli ho nahoře vyberte. Jinak založte nový přes vytvoření projektu (název třeba Odskrtnik).

2. Povolte tři API

U každého klikněte na Povolit (Enable):

  • Google Drive API – zakládání a sdílení seznamů,
  • Google Sheets API – položky a zatržítka v tabulce,
  • Google Picker API – okno Google Disku pro otevření sdíleného seznamu.

3. Souhlasová obrazovka

Pokud ji projekt už má, krok přeskočte. Jinak v Google Auth Platform → Začít, název Odškrtník, váš e-mail, cílová skupina Externí; pak v Audience Publikovat aplikaci.

Proč publikovat? V režimu Testing Google po 7 dnech zruší přihlášení a mohli by se přihlásit jen ručně přidaní testovací uživatelé. Publikovaná (neověřená) aplikace zvládne až 100 uživatelů; při přihlášení ukáže varování „Google tuto aplikaci neověřil“.

Volitelně v Data access přidejte oprávnění https://www.googleapis.com/auth/drive.file.

4. Client ID

V Clients otevřete klienta typu Webová aplikace (nebo ho vytvořte). V Authorized JavaScript origins mějte https://n-yachts.github.io a pro spouštění na počítači http://localhost:8082. Client ID zkopírujte a vložte do průvodce.

5. API klíč

Okno Google Disku (Picker), přes které otevřete seznam, který vám někdo nasdílel, potřebuje API klíč:

  1. V Credentials klikněte na Create credentials → API key.
  2. Klíč omezte (Edit API key): Application restrictions → Websites: https://n-yachts.github.io/* a http://localhost:8082/*; API restrictions → Restrict key → Google Picker API. Uložte.
  3. Zkopírujte klíč (začíná AIza) a vložte ho do průvodce.

Díky omezení klíč nikdo jiný nevyužije. Ukládá se jen ve vašem prohlížeči.

6. Přihlášení

  1. Klikněte na Přihlásit se přes Google a vyberte účet.
  2. Při varování „Google tuto aplikaci neověřil“ klikněte na Pokračovat (případně Rozšířené → Přejít na …). Je to vaše vlastní aplikace.
  3. Povolte přístup „k souborům Disku, které s touto aplikací používáte“.

Přihlášení platí asi hodinu. Když vyprší, u názvu seznamu se objeví 🔑 Obnovit přihlášení – seznam mezitím dál funguje a změny počkají.

Seznamy a předlohy

Na úvodní obrazovce Moje seznamy vidíte všechny seznamy a u každého, kolik je odškrtnuto.

Tlačítkem + Nový seznam založíte seznam z předlohy, kterou si pak upravíte podle sebe:

⛵ Před vyplutímmotor, loď, bezpečnost, navigace, posádka, odplutí
❄️ Zazimování lodimotor, voda a sanita, elektro, interiér, paluba a plachty, papíry
🧳 Balení na cestydoklady, oblečení, hygiena, elektronika, výbava, před odjezdem – s typy hory, moře, služební cesta
📝 Prázdný seznamotevře se rovnou v úpravách

Odškrtávání

  • Klepněte kamkoli na řádek položky – odškrtne se. Druhým klepnutím se vrátí.
  • Nahoře je postup (např. 6 / 31) a co právě probíhá: název, typy a kdy se začalo.
  • Klepnutím na název kategorie ji sbalíte nebo rozbalíte. U kategorie je vidět, kolik je hotovo.
  • Skrýt hotové schová odškrtnuté položky i celé hotové kategorie – zbude jen to, co ještě chybí.
  • U sdíleného seznamu je u odškrtnuté položky vidět, kdo ji odškrtl.
  • Když je odškrtnuto všechno, panel zezelená: 🎉 Vše odškrtnuto.

Začít znovu

Před každým vyplutím nebo balením klepněte na ↺ Začít znovu. Všechna zatržítka se vynulují. Můžete zadat i název (např. „Krkonoše – leden“), který se pak ukazuje nahoře a v historii.

Typy výletu

Pokud mají položky v seznamu typy, vyberete v okně Začít znovu, na co se chystáte. Můžete vybrat i víc typů najednou (třeba hory + služební cesta). V seznamu pak budou:

  • položky bez typu – ty jsou vždy (doklady, nabíječka…),
  • položky, které mají aspoň jeden z vybraných typů.

Když nevyberete nic, budou v seznamu všechny položky. Dole v okně vidíte, kolik položek bude k odškrtnutí.

Historie

Pokud bylo v předchozím průchodu něco odškrtnuto, uloží se při Začít znovu do historie: kdy se začalo a skončilo, typy, název a kolik bylo hotovo. Najdete ji v menu ⋯ → Historie průchodů – hodí se třeba pro „kdy jsme naposledy zazimovali“.

Úpravy položek

V menu ⋯ → Upravit položky se seznam přepne do úprav. Vidíte v něm všechny položky (i ty, které do aktuálního výletu nepatří – jsou zešedlé) a jejich typy.

  • Klepnutím na položku ji upravíte: název, kategorie, typy, poznámka; nebo ji smažete (dvojím klepnutím na Smazat).
  • Šipkami ▲ ▼ změníte pořadí v rámci kategorie.
  • + Přidat do „kategorie“ pod každou kategorií, nebo + Položka nahoře. Novou kategorii založíte tak, že u položky napíšete nový název kategorie.
  • Typy pište oddělené čárkou (hory, moře), nebo klepněte na nabízené typy pod polem. Prázdné pole = položka patří vždy. Nový typ vznikne prostě tím, že ho napíšete.

Úpravy ukončíte tlačítkem Hotovo.

V Google Tabulkách

Každý seznam je Google Tabulka „Odškrtník – název“ ve složce Odškrtník ve vašem Disku (menu ⋯ → Otevřít v Google Tabulkách). Delší seznam se v tabulce upravuje pohodlněji než v telefonu.

  • Prázdná kategorie znamená „stejná jako řádek nad ním“ – stačí ji napsat u první položky skupiny. Aplikace ji pak doplní i do dalších řádků.

Nepřejmenovávejte listy ani sloupce a neměňte hodnoty ve sloupci id – podle nich Odškrtník položky poznává.

Sdílení

Nasdílet seznam

  1. V seznamu klepněte na 👥 Sdílet.
  2. Napište e-mail Google účtu (posádka, rodina…) a klepněte na Sdílet.
  3. Dotyčnému přijde e-mail od Googlu s odkazem na Odškrtník.

V okně sdílení vidíte, kdo má přístup, a jako vlastník ho můžete odebrat. Je tam i odkaz na seznam, který můžete poslat třeba přes WhatsApp – funguje ale jen lidem, se kterými je seznam sdílený.

Otevřít seznam, který vám někdo nasdílel

Odškrtník má přístup jen k tabulkám, které mu výslovně ukážete. Proto je potřeba sdílený seznam jednou potvrdit v okně Google Disku:

  1. Otevřete odkaz z e-mailu (nebo v přehledu klepněte na 📥 Otevřít sdílený).
  2. Klepněte na Zpřístupnit seznam. Otevře se okno Google Disku se seznamem.
  3. Vyberte ho a klepněte na Vybrat. Hotovo – seznam už máte mezi svými natrvalo.
Seznam v okně nevidíte? Zkontrolujte, že jste v Odškrtníku přihlášeni stejným účtem, na jehož e-mail byl seznam sdílen.

Ukládání a bez signálu

Pod názvem seznamu je vidět stav:

✓ Uloženo · právě teďvše je v Google Tabulce
⟳ Ukládám…změny se právě odesílají
📶 Offline · ⏳ 1 změna čekábez signálu – změny počkají v telefonu a odešlou se po připojení
🔑 Obnovit přihlášenípřihlášení vypršelo – klepněte; změny mezitím čekají
  • Změny od ostatních se načítají každých 15 sekund, když máte seznam otevřený, a hned po návratu do aplikace.
  • Seznam se ukládá i do telefonu, takže v marině bez signálu ho pořád vidíte a můžete odškrtávat. Když otevřete aplikaci bez přihlášení, ukáže se rovnou naposledy otevřený seznam.
  • Když dva lidé změní stejnou položku současně, platí poslední změna.

Instalace do telefonu

  • Android (Chrome): tlačítko 📲 Nainstalovat v aplikaci, nebo menu ⋮ → Nainstalovat aplikaci.
  • iPhone (Safari): Sdílet → Přidat na plochu (Client ID a API klíč bude potřeba zadat znovu).
  • Počítač: ikona instalace v adresním řádku Chromu nebo Edge.

Aplikace se přizpůsobí i tmavému režimu.

Řešení potíží

Nevidím novou verzi

Načtěte stránku znovu s Ctrl+Shift+R, v telefonu aplikaci zavřete a otevřete. Verzi vidíte v Nastavení.

„V Google Cloud není povolené Google Drive API“

API je potřeba povolit ve stejném projektu, ke kterému patří Client ID (číslo projektu je v hlášce i na začátku Client ID). Zkontrolujte, že máte nahoře v konzoli vybraný správný projekt, a povolte Drive API, Sheets API a Picker API. Po povolení počkejte pár minut. Vaše seznamy ani změny se mezitím neztratí.

Google Picker API není v omezeních API klíče

V nabídce API restrictions se ukazují jen povolená API – nejdřív Picker API povolte a stránku klíče obnovte. Případně zvolte Don't restrict key a nechte jen omezení na weby.

Chyba origin_mismatch

V Client ID chybí https://n-yachts.github.io (nebo http://localhost:8082) v Authorized JavaScript origins.

Okno Google Disku se neotevře nebo hlásí chybu

Zkontrolujte, že je povolené Google Picker API a že API klíč má v omezeních adresu https://n-yachts.github.io/* a API Google Picker API. Klíč změníte přes Nastavení → Znovu spustit průvodce.

„K seznamu už nemáte přístup“

Vlastník seznam smazal nebo vám odebral sdílení. Seznam zmizí z vašeho přehledu.

Kamarád nemůže přihlásit (access_denied)

Aplikace je v Google Cloud v režimu Testing. Publikujte ji (krok 3), nebo ho přidejte mezi Test users.

Upravil(a) jsem tabulku ručně a v aplikaci to není vidět

Změny ostatních (i ruční úpravy v Tabulkách) se načítají každých 15 s, když je seznam otevřený. Přepněte se z aplikace a zpět, nebo seznam zavřete a otevřete.

Soukromí a oprávnění

Odškrtník žádá jen oprávnění drive.file – vidí a mění jen tabulky, které sám založil, nebo které mu ukážete v okně Google Disku. Ostatní soubory ve vašem Disku nevidí.

Data jsou jen v Google Tabulkách a v mezipaměti vašeho prohlížeče. Aplikace nemá server a nic nesleduje. Přístup odeberete v nastavení Google účtu.
